# Σχέδιο Δημιουργίας Wordboard Activities από Μαθήματα Πληροφορικής

## Σύνοψη
- **6 τάξεις**: dimA, dimB, dimC, dimD, dimE, dimST
- **30 μαθήματα ανά τάξη** (lesson01 - lesson30, lesson00 = περιεχόμενα)
- **7 τύποι δραστηριοτήτων**: quiz, match, wordsearch, missingword, wheel, crossword, groupsort
- **Σύνολο**: 180 μαθήματα × 7 = **1.260 JSON αρχεία**

## Ονοματολογία
- **Filename**: `dimX-lesZZ-timestamp.json` (π.χ. `dimA-les01-6abc123def456.json`)
- **ID πεδίο**: `dimX-lesZZ-timestamp` (ίδιο με filename χωρίς .json)
- **Tags**: `["dimX", "lesZ", "keyword"]` — keyword = 1 λέξη θέματος μαθήματος
- **Χώρα αποθήκευσης**: `/opt/lampp/htdocs/img/wordboard/admin/activities/{type}/`

## JSON Format ανά Τύπο

### quiz
```json
{
  "id": "dimX-lesZ-timestamp",
  "title": "Τίτλος μαθήματος - Quiz",
  "type": "quiz",
  "created_by": "admin",
  "created_date": "2026-04-22",
  "data": {
    "questions": [
      { "question": "...", "options": ["α","β","γ","δ"], "correct": 0 }
    ]
  },
  "tags": ["dimX", "lesZ", "keyword"]
}
```

### wordsearch
```json
{
  "id": "dimX-lesZ-timestamp",
  "title": "Τίτλος μαθήματος - Αναζήτηση Λέξεων",
  "type": "wordsearch",
  "created_by": "admin",
  "created_date": "2026-04-22",
  "data": {
    "grid": [["Α","Β",...], ...],
    "words": ["ΛΕΞΗ1", "ΛΕΞΗ2", ...]
  },
  "tags": ["dimX", "lesZ", "keyword"]
}
```
**ΣΗΜΑΝΤΙΚΟ για wordsearch grid:**
- ΜΗΝ χρησιμοποιείς `#` για κενά κελιά
- Γέμιζε ΟΛΑ τα κελιά του grid με γράμματα
- Οι λέξεις-στόχοι τοποθετούνται οριζόντια ή κάθετα μέσα στο grid
- Τα υπόλοιπα κελιά γεμίζουν με **τυχαία ελληνικά γράμματα** (Α Β Γ Δ Ε Ζ Η Θ Ι Κ Λ Μ Ν Ξ Ο Π Ρ Σ Τ Υ Φ Χ Ψ Ω)
- Μέγεθος grid: 10x12 ή 12x12 (γραμμές x στήλες) στάνταρ, μεγαλύτερο αν χρειάζεται
- 5-8 λέξεις ανά wordsearch
- Λέξεις τοποθετούνται **οριζόντια**, **κάθετα** ΚΑΙ **διαγώνια** (↘ ↗)
- ΝΑ ΘΥΜΑΣΑΙ: admin/activities/wordsearch/activity_69823d3d3d9055.86320476.json αλλά με ελληνικά γράμματα αντί για #
- ΠΟΤΕ μην αναφέρεις λέξη που δεν υπάρχει στο grid (κατέστρεφε το παιχνίδι σε 74/185 αρχεία πριν το fix) — grid μεγαλώνει στο μήκος της μεγαλύτερης λέξης. Η λέξη ΨΗΦΙΑΚΑΔΕΔΟΜΕΝΑ αντικαταστάθηκε με ΨΗΦΙΑΚΑ + ΔΕΔΟΜΕΝΑ απευθείας στα words των dimC-les09-wordsearch-rld.json και dimD-les11-wordsearch-af5.json (2026-09-17) — οι generators ΔΕΝ σπάουν λέξεις μόνοι τους
- Generators (διορθωμένα 2026-09-17): `wordseach_generatorPHP/generate_wordsearch_v2.php` (νέα αρχεία, id `dimX-lesNN-wordsearch-XXX`, γράφει στο admin/activities/wordsearch/ + index.json) και `wordseach_generatorPHP/wordserach3_fixgrids.php` (ξαναχτίζει grid από τις λέξεις υπαρχόντων JSON — τρέξε το χειροκίνητα)

### crossword
```json
{
  "id": "dimX-lesZ-timestamp",
  "title": "Τίτλος μαθήματος - Σταυρόλεξο",
  "type": "crossword",
  "created_by": "admin",
  "created_date": "2026-04-22",
  "data": {
    "grid": [["#","Α",...], ...],
    "words": [
      { "number": 1, "direction": "across", "clue": "...", "answer": "...", "row": 0, "col": 0 }
    ]
  },
    "tags": ["dimX", "lesZ", "keyword"]
}
```
**ΣΗΜΑΝΤΙΚΟ για crossword (από 2026-09-17):**
- Το grid κρατά τα ΓΡΑΜΜΑΤΑ-ΛΥΣΗ (όχι τυχαία γράμματα)· "#" = μαύρο κελί· οι γραμμές ΠΑΝΤΑ arrays από γράμματα (όχι strings — σπάει το JS σε ελληνικά)
- Κάθε answer πρέπει να ταιριάζει ακριβώς με τα γράμματα του grid στη θέση row/col/direction του — αλλιώς το παιχνίδι είναι άλυτο (ήταν χαλασμένο σε 146/181 αρχεία πριν το fix)
- Οι λέξεις πρέπει να ΣΤΑΥΡΩΝΟΝΤΑΙ (across × down σε κοινά γράμματα)· οι αριθμοί (number) μοιράζονται όταν across+down ξεκινούν από το ίδιο κελί
- ΟΧΙ αγγλικές λέξεις μέσα σε ελληνικό σταυρόλεξο (τα 6 μικτά αρχεία διορθώθηκαν στα δεδομένα: bit→ΜΠΙΤ, istos→ΙΣΤΟΣ, email→ΤΑΧΥΔΡΟΜΕΙΟ, web/URL→ΙΣΤΟΣΕΛΙΔΑ, chat→ΣΥΝΟΜΙΛΙΑ, WIFI→ΑΣΥΡΜΑΤΟ, AVATAR→ΕΙΚΟΝΑ, BLOGGER→ΣΥΓΓΡΑΦΕΑΣ)
- Generator fix: `wordseach_generatorPHP/crossword_fixgrids.php` — ξαναχτίζει grid + θέσεις/αριθμούς από τα data.words (κρατάει clues), τρέξε το χειροκίνητα

### groupsort
```json
{
  "id": "dimX-lesZ-timestamp",
  "title": "Τίτλος μαθήματος - Ομαδοποίηση",
  "type": "groupsort",
  "created_by": "admin",
  "created_date": "2026-04-22",
  "data": {
    "groups": [
      { "name": "Κατηγορία Α", "items": ["όρος1", "όρος2"] },
      { "name": "Κατηγορία Β", "items": ["όρος3", "όρος4"] }
    ]
  },
  "tags": ["dimX", "lesZ", "keyword"]
}
```

## NOTE: Wordsearch αναβολή
Τα wordsearch JSON αφήνονται για το τέλος. Δημιουργούμε πρώτα τα 6 άλλα activity types (quiz, match, missingword, wheel, crossword, groupsort) για όλα τα μαθήματα. Τα wordsearch θα γίνουν στο τέλος με script ή χειροκίνητα.

## Διαδικασία ανά Μάθημα
1. Διάβασε HTML αρχείο μαθήματος
2. Εξήγασε βασικές έννοιες, όρους, ορισμούς
3. Δημιούργησε 7 JSON (έναν ανά τύπο δραστηριότητας)
4. Αποθήκευσε στον αντίστοιχο φάκελο τύπου
5. Μάρκαρε μάθημα ως ολοκληρωμένο ☑
