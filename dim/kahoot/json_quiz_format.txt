================================================================================
  KARAQUIZ - QUIZ JSON FORMAT SPECIFICATION
  For AI Agents: Generate quizzes compatible with this Kahoot clone
===============================================================================

⚠️ IMPORTANT NOTE ABOUT "AUTO-GENERATED" FIELDS
The notes below say that "id", "created_at", and "updated_at" are auto-generated
and can be omitted. This is TRUE when importing via the admin UI or API.

However, when placing JSON files directly in data/quiz/ (which is how the
quiz-generation pipeline works), the app reads them directly and these fields
MUST be present. See the sample files in data/quiz/ for the correct format.

Required fields when writing files directly to data/quiz/:
- Top-level: "id" (filename without .json), "title", "questions", "created_at"
- Per-question: "id" (unique string), "text", "answers", "correct"=

This document defines the exact JSON format used by the KaraQuiz application.
Any AI agent can use this spec to generate quiz JSON that is directly importable
via the app's "Import JSON" feature or the import_json API endpoint.

================================================================================
1. QUIZ JSON STRUCTURE (TOP LEVEL)
================================================================================

{
    "title":                "string (REQUIRED) - Quiz title, max ~100 chars",
    "description":          "string (OPTIONAL) - Short description of the quiz",
    "category":             "string (OPTIONAL) - Subject/category (e.g. 'Math', 'Science')",
    "tags":                 "string (OPTIONAL) - Comma-separated tags for filtering",
    "questions":            [ ... array of question objects (REQUIRED, min 1) ... ],
    "randomize_questions":  "boolean (OPTIONAL, default false) - Shuffle question order per game",
    "randomize_answers":    "boolean (OPTIONAL, default false) - Shuffle answer order per question",
    "allow_solo":           "boolean (OPTIONAL, default false) - Allow solo (no PIN) play"
}

NOTES:
  - "id" is AUTO-GENERATED on import. Omit it or leave as empty string "".
  - "created_at" is AUTO-GENERATED on import. Omit it or leave as empty string "".
  - "updated_at" is set automatically on edit. Omit it.

================================================================================
2. QUESTION OBJECT STRUCTURE (inside "questions" array)
================================================================================

{
    "text":        "string (REQUIRED) - The question text",
    "answers":     [ "string", "string", ... ],
    "correct":     "integer (REQUIRED) - 0-based index of the correct answer in the answers array",
    "explanation": "string (OPTIONAL, default '') - Explanation shown after answering",
    "time":        "integer (OPTIONAL, default 20) - Time limit in seconds",
    "points":      "integer (always 1000, can omit)"
}

NOTES:
  - "id" is AUTO-GENERATED on import. Omit it or leave as empty string "".
  - "answers" must contain 2, 3, or 4 non-empty strings.
  - "correct" must be a valid index: 0 for the first answer, 1 for the second, etc.
  - "correct" must be >= 0 and < length of "answers" array.
  - "time" allowed values: 10, 15, 20, 25, 30, 60, 90, 120, or 0 (no limit).
    Any value outside 10-120 is clamped. Default is 20.
  - "points" is always 1000 (the app handles speed/streak multipliers internally).

================================================================================
3. VALIDATION RULES (enforced by the import endpoint)
================================================================================

The following checks are performed when importing a quiz JSON:

  [FAIL] Missing "title" field or empty title                -> Error
  [FAIL] Missing "questions" field or empty questions array   -> Error
  [FAIL] Any question with empty "text"                       -> Question SKIPPED
  [FAIL] Any question with empty "answers" array              -> Question SKIPPED
  [FAIL] Any question missing "correct" field                 -> Question SKIPPED
  [FAIL] Any question with fewer than 2 non-empty answers     -> Question SKIPPED
  [FAIL] "correct" index out of range for that question       -> Error (fatal)
  [FAIL] All questions invalid (none pass validation)         -> Error

  If SOME questions are invalid but at least 1 is valid, the valid ones are kept.

================================================================================
5. QUICK-REFERENCE: FIELD SUMMARY
================================================================================

QUIZ-LEVEL FIELDS
  title                 string    REQUIRED    Quiz title
  description           string    optional    Short description
  category              string    optional    Subject category
  tags                  string    optional    Comma-separated tags
  questions             array     REQUIRED    Min 1 question
  randomize_questions   boolean   optional    default: false
  randomize_answers     boolean   optional    default: false
  allow_solo            boolean   optional    default: false

QUESTION-LEVEL FIELDS
  text                  string    REQUIRED    Question text
  answers               array     REQUIRED    2-4 non-empty strings
  correct               integer   REQUIRED    0-based index into answers[]
  explanation           string    optional    Shown after answering (default: "")
  time                  integer   optional    Seconds: 10|15|20|25|30|60|90|120|0 (default: 20)
  points                integer   optional    Always 1000 (can omit)

AUTO-GENERATED (omit these, the app creates them)
  id                    string    ignored     Unique quiz/question ID
  created_at            string    ignored     "YYYY-MM-DD HH:MM:SS"
  updated_at            string    ignored     "YYYY-MM-DD HH:MM:SS"

================================================================================
6. IMPORT INSTRUCTIONS
================================================================================

Once you have a valid quiz JSON, you can import it into the app in two ways:

METHOD A: Via the Web UI
  1. Log in as admin
  2. Go to "Create Quiz" page
  3. Click the "JSON Code" tab/section
  4. Paste the quiz JSON into the textarea
  5. Click "Import JSON"

METHOD B: Via the API (for automation/scripts)
  POST to: /api/quiz.php
  Form data:
    action    = import_json
    quiz_json = <your JSON string>

  Example with curl:
    curl -X POST http://localhost/kahoot012d/api/quiz.php \
         -d "action=import_json" \
         -d "quiz_json={\"title\":\"My Quiz\",\"questions\":[...]}" 

  Response on success: {"success":true}
  Response on failure: {"success":false,"error":"error message"}
