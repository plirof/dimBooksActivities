## Per-Lesson Workflow (7 steps)
For each `class-X / lesson-N`:

1. **Read source** — `TPE-dimX-PEDIO/lessons_seperated/lessonNN.html` (primary). Skim `περιλήψεις.md` + activities JSON for context.
2. **Copy template** —
   ```bash
   cp tts/slide_TTS_template.html TPE-dimX-PEDIO/presentations/lessonNN.html
   ```
3. **Edit `LESSON` object** — set `number`, `unit`, and `slides[]` (**10–14 slides** per the full-theory spine in "Slide Structure" below; first must be `title`, last must be `assessment` with `end: "Μπράβο! ✦ Τέλος ✦"`).
4. **Sync `slideTexts[]`** — regenerate from `LESSON.slides` via the Node snippet in `AI_AGENT_INSTRUCTIONS.md` §Step 4; paste into the `slideTexts` block.
5. **Generate MP3s** —
   **IMPORTANT: If updating an existing presentation, delete old MP3s first:**
   ```bash
   rm TPE-dimX-PEDIO/presentations/audio/lessonNN/*.mp3
   ```
   ```bash
   mkdir -p TPE-dimX-PEDIO/presentations/audio/lessonNN
   ./tts/pregen.AppImage \
     TPE-dimX-PEDIO/presentations/lessonNN.html \
     TPE-dimX-PEDIO/presentations/audio/lessonNN
   ```
6. **Verify in browser** — load `lessonNN.html`; confirm audio plays, auto-advance works; test `?speed=0.7` and `?mode=manual`.
7. **Update tracker** — in `tts/tts_implementation_track.md`, set the row's HTML = ✅ and MP3 = ✅.

## Slide Structure (full-theory, 10–14)
Slides must let the teacher present **all the theory without the book**. Full-theory spine:
`title → concept(big idea / why it matters) → concept(each principle) → list(glossary — every new term) → text(worked example) → steps(procedure) → practice → assessment`
- **Every** distinct concept/definition in the source lands on a slide — never cut one to stay short; raise the count instead (up to ~14).
- Theory-heavy lessons: 10–14 slides. Genuinely light lessons: 8–10.
- Tracker marks these `✅FT` (full theory).
- Never add a `tts` field (auto-generated at runtime by `getSlideText()` in `tts/scripts/presentation.js`).
- Always end with an `assessment` slide.

## URLs & Keyboard (browser testing)
| Param / Key | Effect |
|-------------|--------|
| `?speed=0.7` | Slower playback (range 0.5–2.0, default 0.85) |
| `?mode=manual` | Manual navigation — **no narration and no auto-advance** (silent, slides change only by ←/→; applies to every engine: MP3, `?tts=web`, `?tts=piper`) |
| `?tts=web` | Narrate with the browser's Web Speech engine instead of the MP3s (MP3s stay the default). Needs a Greek system voice on Linux: `speech-dispatcher` + `speech-dispatcher-espeak-ng` + `espeak-ng` — Firefox works natively, Chromium/Chrome need `--enable-speech-dispatcher` |
| `?tts=piper` | Narrate with the local Piper neural voice (`el_GR-rapunzelina`, synthesized in-browser via WASM from `tts/piper/`). Fully offline, no MP3s fetched, Chrome only. Falls back to Web Speech if the engine fails. See `tts_piper_implementation260906instructions.md` |
| ← / → | Previous / Next slide |
| Space | Pause / Resume autoplay |
| M | Mute / Unmute |
| F | Toggle fullscreen |
| + / − | Speed up / slow down |
