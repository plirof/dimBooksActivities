Οργάνωση και διαχείριση δεδομένων 
έρευνας στο υπολογιστικό φύλλο

     Μάθημα 17ο

  Να οργανώνεις και να διαχειρίζεσαι δεδομένα έρευνας για την 

επίλυση προβλημάτων. 

  Να αξιοποιείς τα διαγράμματα στο υπολογιστικό φύλλο για να 

παρουσιάσεις πληροφορίες και να απαντήσεις σε ερωτήματα. 

Στο μάθημα αυτό θα μάθεις:

Θυμάμαι ότι… Για να οργανώσω τα δεδομένα μιας έρευνας στο υπολογιστικό φύλλο, για κάθε 

ερώτηση μετράω τις απαντήσεις που δόθηκαν σε κάθε διαφορετική επιλογή της ερώτησης.

Θα οργανώσουμε τα δεδομένα που συλλέξαμε σε πίνακες και διαγράμματα  
με το υπολογιστικό φύλλο. Θα μπορέσουμε έτσι να αναλύσουμε τα δεδομένα  

και να απαντήσουμε στις ερωτήσεις.
