# AGENTS.md — Οδηγός για agents

Αυτός ο φάκελος περιέχει τα βιβλία Πληροφορικής (Πληροφορική και ΤΠΕ) Δημοτικού Σχολείου, μετατραπένα από PDF σε HTML μέσω `pdftohtml`.

## Important
- Before you change a file, make a backup of it in [root of this project]/backup_/ folder. The filename of the backup will be : [filename]YYMMDD.[ext]
- Ignore contents inside [root of this project]/backup_/ . Do not search inside this folder or modify anything. THis is a backup folder.

## Δομή φακέλων

Κάθε υποφάκελος `TPE-dimX-PEDIO` περιέχει:
- `index.html` — Ολόκληρο το βιβλίο σε μορφή HTML (μεγάλο αρχείο, εκατοντάδες σελίδες). Το κείμενο βρίσκεται μέσα σε `<p>` tags με absolute positioning. Κάθε σελίδα ξεκινά με σχόλιο `<!-- Page N -->` και anchor `<a name="N">`.
- `img/` — Φάκελος με εικόνες PNG (μία ανά σελίδα, `indexNNN.png`).
- `περιλήψεις.md` — Σύντομες περιλήψεις (2-4 γραμμές) ανά μάθημα.

## Πώς να διαβάσεις το περιεχόμενο ενός μαθήματος από το HTML

1. Βρες τον πίνακα περιεχομένων (συνήθως σελίδα 8 ή 9, anchor `#8` ή `#9`). Κάθε μάθημα έχει αριθμό και τίτλο με link π.χ. `<a href="index.html#11">`.
2. Το anchor number στο link αντιστοιχεί σε σελίδα του βιβλίου, όχι σε αριθμό μαθήματος. Πήγαινε στο αντίστοιχο `<!-- Page N -->`.
3. Το κείμενο βρίσκεται σε `<p>` tags. Αγνόησε CSS styles και absolute positions — ψάξε μόνο το text content.
4. Κάθε μάθημα διαρκεί συνήθως 2-4 σελίδες.

## Δραστηριότητες (Activities)

### Σχεδιασμός

Κάθε τάξη έχει ένα αρχείο `activities_X.md` (π.χ. `activities_C.md`) που περιγράφει 3 δραστηριότητες ανά μάθημα (90 συνολικά ανά τάξη).

### Ονομασία JSON αρχείων

Τα JSON αρχεία δραστηριοτήτων ακολουθούν τη μορφή:

```
dim{Class}-les{LessonNumber}-{ActivityType}-{3RandomChars}.json
```

Παράδειγμα: `dimB-les05-quiz-KG7.json`

- `{Class}`: A, B, C, D, E, ST (τάξη)
- `{LessonNumber}`: 01-30
- `{ActivityType}`: quiz, memory, drag-categories, drag-order, grid-game, click-game, falling-letters, canvas-pixels, arcade-game, guess-number, qr-scanner, spreadsheet-filter
- `{3RandomChars}`: 3 τυχαία αλφαριθμητικά χαρακτήρες (π.χ. KG7, A1B, XYZ)

Ο τύπος δραστηριότητας εξάγεται από το όνομα αρχείου και αντιστοιχεί σε έναν από τους 12 σκελετούς.

### Σκελετοί (activities-base/)

Ο φάκελος `activities-base/` περιέχει 12 **self-contained HTML skeletons** — καθένας φορτώνει δεδομένα από εξωτερικό JSON αρχείο μέσω `?data=path/to/file.json`. Αναλυτική τεκμηρίωση: `activities-base/activities-base-documentation.md`.

| Σκελετός | Τύπος δραστηριότητας |
|----------|---------------------|
| `quiz.html` | Κουίζ πολλαπλής επιλογής & Σωστό/Λάθος |
| `drag-categories.html` | Drag-and-drop σε κατηγορίες/στήλες |
| `drag-order.html` | Σειροθέτηση βημάτων |
| `memory.html` | Memory / ταίριασμα ζευγαριών |
| `grid-game.html` | Πλέγμα + εντολές κίνησης |
| `falling-letters.html` | Πληκτρολόγηση (falling letters) |
| `click-game.html` | Κλικ σε στόχους |
| `canvas-pixels.html` | Pixel art / χρωματισμός grid |
| `arcade-game.html` | Arcade παιχνίδι (σκορ, νίκη, ήττα) |
| `guess-number.html` | Μάντεψε αριθμό (μεγαλύτερο/μικρότερο) |
| `qr-scanner.html` | QR scanner simulation |
| `spreadsheet-filter.html` | Φιλτράρισμα δεδομένων spreadsheet |

### Πώς δημιουργείς νέα δραστηριότητα

1. Βρες το `activities_X.md` της τάξης → διάβασε τις δραστηριότητες του μαθήματος
2. Διάλεξε σκελετό βάσει τύπου (quiz, drag-categories, κ.λπ.)
3. Δημιούργησε JSON αρχείο με τα δεδομένα → αποθήκευσε στον φάκελο `activities/` της τάξης με όνομα της μορφής `dimX-les{Lesson}-{Type}-{3chars}.json`
4. Κλήση: `skeleton.html?data=../TPE-dimX-PEDIO/activities/dimX-lesNN-{type}-XXX.json`

Παράδειγμα: `quiz.html?data=../TPE-dimC-PEDIO/activities/dimC-les01-quiz-YCB.json`

### JSON δομές

Αναλυτικές δομές JSON ανά σκελετό + sample αρχεία: βλ. `activities-base/activities-base-documentation.md`.

## Σημείωση

Όλα τα κείμενα είναι στα Ελληνικά. Τα βιβλία εκδόθηκαν από το Υπουργείο Παιδείας / ΙΕΠ / Εκδόσεις Πεδίο «Διόφαντος».

### Τεχνικές σημειώσεις

- Η συνάρτηση `detectType()` στο `index.php` μπορεί να αφαιρεθεί αν ο τύπος εξάγεται πάντα από το όνομα αρχείου. Διατηρείται προς το παρόν για τα HTML αρχεία στο `activities-unique/` (τα οποία δεν έχουν τον τύπο στο όνομα).
- Η λογική αντιστοίχισης αρχείων στο `index.php` βασίζεται στο regex: `/dim[A-Z]_les(\d+)-([a-z-]+)-([a-zA-Z0-9]{3})\.json/`
