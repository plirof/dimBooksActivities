# Track File — Custom Unique Activities

## Naming Convention
```
dimX-lesNN-custom-[2-3-words].html
```
Π.χ. `dimC-les15-custom-ierarxikos-xartis.html`

## Output Directory
`activities-unique/` (flat, no subfolders)

## Activity Design Guidelines
- **Standalone HTML** — inline CSS + JS, no external dependencies
- **Interactive** — όχι παθητικό quiz· ο μαθητής κάνει κάτι (σέρνει, ταξινομεί, χτίζει, επιλέγει, πειραματίζεται)
- **Emoji fallback** — χρήση `@font-face` από `fonts/NotoColorEmoji.ttf` (unicode-range: emoji blocks)
- **Γλώσσα** — όλα στα Ελληνικά
- **Ηλικιακά κατάλληλο** — απλότητα/πολυπλοκότητα ανάλογα με την τάξη
- **Touch-friendly** — υποστήριξη για tablets (touch events).
- **Σχετικό με το μάθημα** — το activity βοηθά στην κατανόηση του συγκεκριμένου θέματος . Διάβασε το μάθημα απο το TPE-dim*-PEDIO/lessons_seperated/ και όχι από τις περιλήψεις (summary_*.md , TPE-dim*-PEDIO/περιλήψεις.md )
- I want the activities to be unique not same as the other activity types (from activity-base/)
- **Θεωρία βιβλίου** — Προσοχή , μην βάλεις δραστηριότητες που βασίζονται σε συγκεκριμένο παράδειγμα του βιβλίου. Πχ "Που πρέπει να πάει η Μαρία;" βασίζεται σε συγκεκριμένο παράδειγμα συγκεκριμένου βιβλίου και δεν βοήθάει πολύ στην κατανόηση.
