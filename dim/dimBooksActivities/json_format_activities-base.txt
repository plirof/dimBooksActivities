================================================================================
  ACTIVITIES-BASE — JSON Format Reference (48 skeletons)
================================================================================

Κατάλογος 48 σκελετών εκπαιδευτικών δραστηριοτήτων.
Κάθε HTML φορτώνει JSON μέσω ?data=file.json.

================================================================================
  1. quiz.html — Κουίζ (Πολλαπλής επιλογής & Σωστό/Λάθος)
================================================================================

Ερωτήσεις μία-μία, με feedback ανά ερώτηση, τελικό σκορ.

{
  "title": string,                // Τίτλος δραστηριότητας
  "subtitle": string,             // Υπότιτλος / οδηγία (προαιρετικό)
  "questions": [
    {
      "text": string,             // Κείμενο ερώτησης
      "type": string,             // "tf" για Σωστό/Λάθος ή "mc" για πολλαπλής επιλογής
      "answer": boolean,          // Μόνο για type "tf": true ή false
      "options": [string],        // Μόνο για type "mc": οι επιλογές
      "correctIndex": number,     // Μόνο για type "mc": index σωστής απάντησης (0-based)
      "explanation": string       // Επεξήγηση μετά την απάντηση (προαιρετικό)
    }
  ]
}

================================================================================
  2. drag-categories.html — Drag σε Κατηγορίες
================================================================================

Ο χρήστης σέρνει στοιχεία (items) και τα τοποθετεί σε κατηγορίες (columns/boxes).
Έλεγχος στο τέλος. Τα items ανακατεύονται αυτόματα.

{
  "title": string,                // Τίτλος δραστηριότητας
  "subtitle": string,             // Υπότιτλος / οδηγία (προαιρετικό)
  "categories": [
    {
      "id": string,               // Μοναδικό αναγνωριστικό κατηγορίας (π.χ. "cat1")
      "name": string,             // Όνομα κατηγορίας
      "color": string             // Hex χρώμα κατηγορίας (π.χ. "#4CAF50")
    }
  ],
  "items": [
    {
      "id": string,               // Μοναδικό αναγνωριστικό στοιχείου
      "text": string,             // Κείμενο στοιχείου (υποστηρίζει emoji)
      "category": string          // category id (αντιστοιχεί σε category.id)
    }
  ]
}

================================================================================
  3. drag-order.html — Σειροθέτηση Βημάτων
================================================================================

Ο χρήστης σέρνει βήματα πάνω-κάτω για να τα βάλει στη σωστή σειρά.
Τα steps ανακατεύονται αυτόματα.

{
  "title": string,                // Τίτλος δραστηριότητας
  "subtitle": string,             // Υπότιτλος / οδηγία (προαιρετικό)
  "steps": [
    { "text": string }            // Κείμενο βήματος (στη ΣΩΣΤΗ σειρά)
  ],
  "successMessage": string        // Μήνυμα επιτυχίας (προαιρετικό)
}

================================================================================
  4. memory.html — Memory / Ταίριασμα Ζευγαριών
================================================================================

Κάρτες ανάποδες — ο χρήστης αναποδά δύο κάθε φορά για να βρει ζευγάρια.
Οι κάρτες ανακατεύονται αυτόματα.

{
  "title": string,                // Τίτλος δραστηριότητας
  "subtitle": string,             // Υπότιτλος / οδηγία (προαιρετικό)
  "columns": number,              // Στήλες grid (προαιρετικό, default: 4)
  "pairs": [
    {
      "cardA": string,            // Κείμενο πρώτης κάρτας (υποστηρίζει emoji)
      "cardB": string             // Κείμενο δεύτερης κάρτας
    }
  ]
}

================================================================================
  5. grid-game.html — Πλέγμα & Εντολές Κίνησης
================================================================================

Grid με χαρακτήρα, εμπόδια, στόχο. Ο χρήστης δίνει εντολές (↑↓←→) και
πατά "Εκτέλεση" για να δει αν φτάνει στον στόχο.

{
  "title": string,                // Τίτλος δραστηριότητας
  "subtitle": string,             // Υπότιτλος / οδηγία (προαιρετικό)
  "gridSize": number,             // Μέγεθος grid NxN (προαιρετικό, default: 8)
  "start": { "row": number, "col": number },  // Αφετηρία (0-based, row=0 είναι πάνω)
  "goal": { "row": number, "col": number },   // Στόχος (0-based)
  "obstacles": [                  // Εμπόδια (προαιρετικό)
    { "row": number, "col": number }
  ]
}

================================================================================
  6. click-game.html — Κλικ σε Στόχους
================================================================================

Στόχοι εμφανίζονται τυχαία — ο χρήστης κάνει κλικ πριν εξαφανιστούν.
Χρονομέτρηση.

{
  "title": string,                // Τίτλος δραστηριότητας
  "subtitle": string,             // Υπότιτλος / οδηγία (προαιρετικό)
  "instructions": string,         // Οδηγίες (προαιρετικό)
  "duration": number,             // Δευτερόλεπτα παιχνιδιού (προαιρετικό, default: 30)
  "maxTargets": number,           // Μέγιστοι στόχοι ταυτόχρονα (προαιρετικό, default: 3)
  "targetLife": number,           // Χιλιοστά ζωής στόχου (προαιρετικό, default: 2000)
  "targets": [
    {
      "label": string,            // Κείμενο/emoji στόχου
      "color": string             // Χρώμα φόντου (hex)
    }
  ]
}

  7. falling-letters.html — Πληκτρολόγηση (Falling)
================================================================================

Γράμματα/λέξεις πέφτουν — ο χρήστης πληκτρολογεί πριν φτάσουν κάτω.

{
  "title": string,                // Τίτλος δραστηριότητας
  "subtitle": string,             // Υπότιτλος / οδηγία (προαιρετικό)
  "instructions": string,         // Οδηγίες στην αρχική οθόνη (προαιρετικό)
  "speed": number,                // Ταχύτητα πτώσης pixels/frame (προαιρετικό, default: 2)
  "lives": number,                // Αριθμός ζωών (προαιρετικό, default: 3)
  "spawnInterval": number,        // Χιλιοστά ανά νέο αντικείμενο (προαιρετικό, default: 2000)
  "items": [
    {
      "text": string,             // Κείμενο που εμφανίζεται
      "key": string               // Τι πληκτρολογεί ο χρήστης (case-insensitive)
    }
  ]
}

================================================================================
  8. canvas-pixels.html — Pixel Art / Χρωματισμός Grid
================================================================================

Grid pixels με παλέτα χρωμάτων — ο χρήστης χρωματίζει.
Αν υπάρχει solution, προστίθενται κουμπιά ελέγχου & εμφάνισης λύσης.

{
  "title": string,                // Τίτλος δραστηριότητας
  "subtitle": string,             // Υπότιτλος / οδηγία (προαιρετικό)
  "rows": number,                 // Γραμμές grid (προαιρετικό, default: 8)
  "cols": number,                 // Στήλες grid (προαιρετικό, default: 8)
  "palette": [string],            // Hex χρώματα. Index 0 = άσπρο (σβήσιμο)
  "solution": [                   // 2D array με indexes στο palette (προαιρετικό)
    [number]                      // solution[row][col] = index στο palette
  ]
}

================================================================================
  9. arcade-game.html — Arcade Παιχνίδι (Δύτης & Αστερίες)
================================================================================

Canvas-based παιχνίδι όπου ένας δύτης μαζεύει ⭐ αστερίες και αποφεύγει 🐡.
Υποστηρίζει ρυθμιστές (sliders), επίπεδα (levels) και εμφάνιση συνθήκης τέλους.

{
  "title": string,                // Τίτλος δραστηριότητας
  "subtitle": string,             // Υπότιτλος / οδηγία (προαιρετικό)
  "winScore": number,             // Πόντοι για νίκη
  "maxLives": number,             // Αρχικές ζωές
  "initialStars": number,         // Αρχικός αριθμός αστεριών
  "initialPuffers": number,       // Αρχικός αριθμός αλιγκάτορ
  "maxPuffers": number,           // Μέγιστος αριθμός αλιγκάτορ
  "pufferSpeed": number,          // Βασική ταχύτητα αλιγκάτορ
  "canvasW": number,              // Πλάτος καμβά (px)
  "canvasH": number,              // Ύψος καμβά (px)
  "hasSliders": boolean,          // Εμφάνιση ρυθμιστών winScore/lives
  "sliderMin": number,            // Ελάχιστη τιμή slider
  "sliderMax": number,            // Μέγιστη τιμή slider
  "hasLevels": boolean,           // 3 επίπεδα με αυξανόμενη δυσκολία
  "levelThemes": [[string]],      // Χρώματα φόντου ανά επίπεδο
  "hasConditionBox": boolean,     // Εμφάνιση block συνθήκης τέλους
  "conditionText": string         // Κείμενο συνθήκης
}

  "range": number,                // Μέγιστος αριθμός (1-range)
  "rounds": number,               // Αριθμός γύρων
  "showTable": boolean,           // Εμφάνιση πίνακα καταγραφής
  "showAverage": boolean,         // Υπολογισμός μέσου όρου
  "showStars": boolean            // Αξιολόγηση με αστέρια
}

  11. qr-scanner.html — QR Scanner Simulation
================================================================================

Προσομοιωμένο QR scanner. Κάρτες QR εμφανίζονται, ο χρήστης σκανάρει
και μαντεύει τον τύπο περιεχομένου.

{
  "title": string,                // Τίτλος δραστηριότητας
  "subtitle": string,             // Υπότιτλος / οδηγία (προαιρετικό)
  "cardsPerRound": number,       // Κάρτες ανά γύρο
  "qrItems": [
    {
      "type": string,             // Τύπος QR (π.χ. "url")
      "icon": string,             // Emoji εικονίδιο (π.χ. "🌐")
      "label": string,            // Ετικέτα (π.χ. "Ιστοσελίδα")
      "content": string,          // Περιεχόμενο QR (π.χ. "https://gov.gr")
      "hint": string,             // Υπόδειξη
      "options": [string],        // 3 επιλογές απάντησης
      "correctIndex": number      // Index σωστής απάντησης (0-based)
    }
  ]
}
